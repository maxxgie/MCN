# MCN - My Campus Network
*Academic Operating System*

MCN is a revolutionary, commercial-grade Academic Operating System that redefines how university students learn, research, collaborate, innovate, and manage their academic lives. More than just an LMS, it's an intelligent ecosystem combining AI tutoring, research tools, productivity suite, coding environment, collaboration features, and career development in one unified platform.

## Vision
To become the first application every university student opens each day - their central hub for everything academic.

## Core Features
- **Campus AI** - Multi-provider AI assistant (OpenAI, Claude, Gemini, DeepSeek, Mistral, Llama, Ollama)
- **Intelligent Dashboard** - Adaptive workspace with widgets, drag-and-drop
- **Advanced Note-Taking** - Markdown, whiteboards, knowledge graphs
- **Research Environment** - Citations, literature review, academic integrations
- **Integrated IDE** - VS Code-inspired with AI pair programming
- **Productivity Suite** - Calendar, tasks, Pomodoro, analytics
- **Collaboration** - Teams, real-time editing, video calls
- **Career Development** - Resumes, interviews, job tracking
- **Offline-First** - Embedded SQLite, works without internet
- **Plugin Architecture** - Extensible without modifying core

## Architecture
Built with Clean Architecture, DDD, SOLID principles. Monorepo structure with multiple apps and shared packages.
